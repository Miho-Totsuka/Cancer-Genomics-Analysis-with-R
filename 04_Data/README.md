# Data

This project uses cancer genomics and clinical data associated with TCGA-KIRC.

The analyses use the following local files:

- `KIRC_mutation.rds`
- `KIRC_expression.rds`
- `KIRC_clinical.rds`

These files are used by the R scripts in the `03_Analysis/` folder.

The data are associated with The Cancer Genome Atlas (TCGA) and the NCI Genomic Data Commons. Some processed files were provided or prepared during the Rosetta Institute Cancer Bioinformatics workshop.

The large data files are not included in this public GitHub repository. They are stored locally and can be obtained or recreated from the original data sources where appropriate.
